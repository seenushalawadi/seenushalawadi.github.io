# Srinivas Vinod Shalawadi — Portfolio

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools are required. The portfolio uses plain HTML, CSS and JavaScript.

## Customize
- Edit content in `index.html`.
- Change colors, spacing and responsive styles in `style.css`.
- Navigation behavior is in `script.js`.
- The original resume PDF is included in `assets/resume_srinivas.pdf`.

The Google Fonts import requires an internet connection; system fallback fonts are provided.
